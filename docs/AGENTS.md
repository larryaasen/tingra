# Agent Rules for `docs/`

These rules add to the monorepo root [AGENTS.md](../AGENTS.md), which still applies in full. `CLAUDE.md` in this folder only imports this file (`@AGENTS.md`) and should not be edited separately.

## What Each Document Holds
- **[ARCHITECTURE.md](ARCHITECTURE.md) records how the system works and why, never the status of the work.** Decisions, their rationale, and what a probe or a check found (stated as a fact) belong there, as do the dates decisions were made. Who checked what by hand and when, checks still to do, test counts, warning-clean or format-clean notes, commit state, and approval mechanics do not: those go in the commit, CHANGELOG.md, and TODO.md.
- **[TYPES.md](TYPES.md) lists every public type** in the monorepo, package by package, each on **one line of at most 80 characters, the list marker and the name included** — a short phrase saying what the type is, never wrapped onto a second line. Detail (history, dates, rationale, behavior) belongs in the type's `///` doc comment or ARCHITECTURE.md, not here; a type worth mentioning gets its own line rather than a clause in another's, and paired names (`A` / `B`) are split into one line each. Update that listing in the same change whenever a public type is added, renamed, or removed — it must never drift from the code. An app exposes no public API beyond its `@main` entry, so an app's entry lists the internal surface a reader needs to navigate the target instead.
- **[README.md](../README.md) lists every package and app on one line each**: its name, linked to its section in [TYPES.md](TYPES.md), and a short phrase saying what it is. Nothing more goes in the README, never a second line or a paragraph. The detail lives in TYPES.md: each package's or app's section opens with a paragraph saying what it is and why it exists, then lists its types. Add both in the same change whenever a package or app is added.
- **[TODO.md](TODO.md) lists only open work:** a finished item is deleted in the same change that finishes it, with CHANGELOG.md and the commit as its record (TODO.md's header owns the rule). [DONE.md](DONE.md) is frozen as of 2026-11-12: never add to it, but leave existing citations of its records in place.
